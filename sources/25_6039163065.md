
✏️ 本文创建于 2025-5-16

[First Contributions](https://github.com/firstcontributions/first-contributions) 是一个引导新手完成第一次开源贡献的练习仓库，完整走一遍 Fork → Clone → Branch → Commit → Push → Pull Request 流程。

## STEP1 Fork 别人的 repo

Fork [first-contributions](https://github.com/firstcontributions/first-contributions) 仓库到自己的账号下。

## STEP2 Clone fork 到自己账号下的 repo

``` bash
git clone https://github.com/interset-wq/first-contributions.git
```

<details>
<summary>note（点击展开）</summary>

此处使用的是 HTTPS，也可以使用 SSH。

</details>

## STEP3 创建一个新分支

1. 切换目录到 clone 到本地的 repo 的目录中
2. 使用 `git switch` 命令新建一个代码分支

    ``` bash
    git switch -c <新分支的名称>
    ```

    此处创建一个 add-myname 分支：

    ``` bash
    git switch -c add-interset-wq
    ```

## STEP4 修改代码，Commit 修改

1. 修改 `Contributors.md` 中的内容
2. 检查状态（可选，输出信息中被修改的文件名会标红）

    ``` bash
    git status
    ```

3. 添加改动

    ``` bash
    git add Contributors.md
    ```

4. 检查状态（可选，刚才标红的文件名现在标绿）
5. 提交修改

    ``` bash
    git commit -m "Add interset-wq to Contributors list"
    ```

6. Push 到 GitHub repo（此处推送的是前面新建的分支）：

    ``` bash
    git push origin add-interset-wq
    ```

## STEP5 Pull Request（PR）

1. fork 来源 repo 的上方会出现 `Compare & pull request` 按钮，点击此按钮
2. 点击 `Create pull request`，正式提交 pull request
