# GFM 扩展语法

GitHub Flavored Markdown 在标准 Markdown 之上的扩展。每节均为「源码 → 渲染效果」对照。

## 一、文本样式扩展

``` text
~~删除线~~ 或 ~单波浪线~
H<sub>2</sub>O 下标
X<sup>2</sup> 上标
<ins>下划线</ins>
```

渲染效果：~~删除线~~、H<sub>2</sub>O、X<sup>2</sup>、<ins>下划线</ins>

## 二、颜色

反引号内写颜色值会渲染成色块（支持 hex / rgb / hsl）：

``` text
`#0969da` `rgb(9, 105, 218)` `hsl(212, 92%, 45%)`
```

渲染效果：`#0969da` `rgb(9, 105, 218)` `hsl(212, 92%, 45%)`

## 三、Emoji

冒号包裹短代码，完整清单见 [emoji-cheat-sheet](https://github.com/ikatyang/emoji-cheat-sheet)：

``` text
:smile: :tada: :rocket: :+1:
```

渲染效果：:smile: :tada: :rocket: :+1:

## 四、脚注

``` text
这里有一个脚注[^1]，还可以多行[^2]。

[^1]: 引用内容。
[^2]: 换行需要在行首加两个空格。
     这是第二行。
```

渲染效果：这里有一个脚注[^1]，还可以多行[^2]。

[^1]: 引用内容。
[^2]: 换行需要在行首加两个空格。
     这是第二行。

## 五、告诫块（Alerts）

五种级别，`>` 内首行写 `[!类型]`：

``` text
> [!NOTE]
> Useful information that users should know, even when skimming content.

> [!TIP]
> Helpful advice for doing things better or more easily.

> [!IMPORTANT]
> Key information users need to know to achieve their goal.

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

> [!CAUTION]
> Advises about risks or negative outcomes of certain actions.
```

渲染效果：

> [!NOTE]
> Useful information that users should know, even when skimming content.

> [!TIP]
> Helpful advice for doing things better or more easily.

> [!IMPORTANT]
> Key information users need to know to achieve their goal.

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

> [!CAUTION]
> Advises about risks or negative outcomes of certain actions.

## 六、折叠区

HTML `<details>` 标签，`summary` 为可见标题：

``` html
<details>
<summary>点击展开</summary>
被折叠的内容。
</details>
```

渲染效果：

<details>
<summary>点击展开</summary>
被折叠的内容。
</details>

## 七、自动链接

裸 URL、@用户名、#issue 号、SHA 均自动转链接：

``` text
https://github.com
@octocat
#47
```

渲染效果：https://github.com、@octocat、#47

## 八、LaTeX 数学（GitHub 支持）

``` text
$\sqrt{3}x^2 + \frac{1}{2}$

$$
\int_a^b f(x)\,dx = F(b) - F(a)
$$
```

渲染效果：

$\sqrt{3}x^2 + \frac{1}{2}$

$$
\int_a^b f(x)\,dx = F(b) - F(a)
$$
