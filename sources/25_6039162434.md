## STEP1 在 Git 中设置用户名和邮箱

Git 使用用户名将提交与身份关联。**Git 用户名与 GitHub 用户名不同**，可以使用任意文本作为 Git 用户名，此用户名只用来显示 repo 的提交信息。

为每个 repo 设置全局用户名 global user.name 和全局邮箱 global user.email：

``` bash
git config --global user.name "user name"
git config --global user.email "email@example.com"
```

检查用户名和邮箱是否设置成功：

``` bash
git config --global user.name
# user name
git config --global user.email
# email@example.com
```

<details>
<summary>单独为某个 repo 设置用户名和邮箱（点击展开）</summary>

1. 切换目录到本地库
2. 为这个 repo 专门设置 git 用户名和邮箱

    ``` bash
    git config user.name "user name"
    git config user.email "email@example.com"
    ```

3. 检查用户名是否设置成功

    ``` bash
    git config user.name
    # user name
    git config user.email
    # email@example.com
    ```

</details>

## STEP2 通过 Git 向 GitHub 进行身份验证

从 Git 连接到 GitHub 仓库时，需要使用 HTTPS 或 SSH 向 GitHub 进行身份验证。通过 HTTPS 连接比较简便，推荐使用。

- **HTTPS**：`git clone https://github.com/USER/REPO.git`，推送时用 Personal Access Token 作为密码（GitHub 已不支持账户密码推送）。
- **SSH**：`ssh-keygen -t ed25519 -C "email@example.com"` 生成密钥，把公钥 `~/.ssh/id_ed25519.pub` 添加到 GitHub → Settings → SSH and GPG keys，之后用 `git@github.com:USER/REPO.git` 地址克隆推送。
