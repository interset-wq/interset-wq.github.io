# Markdown语法

> 本文整理常用 Markdown / GFM 语法，每节均为「源码 → 渲染效果」对照，便于随时查阅。
> GitHub 扩展语法见本页底部系列目录《GFM 扩展语法》。

## 一、标题

`#` 表示标题，一共六级，`#` 与文字之间需有空格。

``` text
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

渲染效果：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 二、段落与换行

段落之间用一个空行分隔。段内换行有三种方式：

``` text
第一行（行尾两个空格）
第二行

或者用 <br> 标签强制换行
```

渲染效果：

第一行（行尾两个空格）
第二行

或者用 <br> 标签强制换行

## 三、列表

### 3.1 无序列表

`-`、`+`、`*` 均可创建无序列表，可嵌套（子项缩进两个空格）：

``` text
- html
- css
  - flex
  - grid
- javascript
```

渲染效果：

- html
- css
  - flex
  - grid
- javascript

### 3.2 有序列表

数字 + `.` 创建有序列表，渲染时自动重排序号：

``` text
1. 英语四级
2. 英语六级
   1. 听力
   2. 阅读
5. 顺序打乱也会显示为 3
```

渲染效果：

1. 英语四级
2. 英语六级
   1. 听力
   2. 阅读
5. 顺序打乱也会显示为 3

### 3.3 任务列表

`- [ ]` 未完成、`- [x]` 已完成（GitHub 上可直接勾选切换）：

``` text
- [ ] 未完成任务
- [x] 已完成任务
```

渲染效果：

- [ ] 未完成任务
- [x] 已完成任务

## 四、强调

``` text
**粗体** 或 __粗体__
*斜体* 或 _斜体_
***粗斜体***
~~删除线~~
行内`代码`用反引号
```

渲染效果：**粗体**、*斜体*、***粗斜体***、~~删除线~~、行内`代码`用反引号

## 五、引用

`>` 创建引用，可嵌套、可包含其他元素：

``` text
> 一级引用
> > 嵌套二级引用
> - 引用里的列表
```

渲染效果：

> 一级引用
> > 嵌套二级引用
> - 引用里的列表

## 六、代码块

三个反引号包裹，标注语言获得语法高亮：

```` text
``` python
def greet(name):
    return f"Hello, {name}!"
```
````

渲染效果：

``` python
def greet(name):
    return f"Hello, {name}!"
```

行内代码用单个反引号：`pip install internote`。

## 七、链接

``` text
[内联链接](https://github.com)
带标题的链接：[GitHub](https://github.com "GitHub 首页")
自动链接：<https://github.com>
```

渲染效果：[内联链接](https://github.com)、[GitHub](https://github.com "GitHub 首页")、<https://github.com>

## 八、图片

``` text
![图片描述](图片地址)
```

![GitHub](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)

## 九、表格

`|` 分列、`---` 分隔行，冒号控制对齐：

``` text
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 默认 | 居中 | 靠右 |
```

渲染效果：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 默认 | 居中 | 靠右 |

## 十、分隔线

三个及以上的 `-`、`*` 或 `_`：

``` text
---
```

渲染效果：

---
